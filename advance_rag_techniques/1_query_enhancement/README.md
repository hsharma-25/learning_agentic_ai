# Query Enhancement Techniques in RAG

- Users generally write short queries or don't ask questions in the same level of detail used in the knowledge base
- These techniques improve the user's queries before they reach the retriever

## Techniques discussed:
1. [Multi-Query-Retriever](agentic_ai/advance_rag_techniques/1_query_enhancement/mqr_retriever.ipynb): Generates multiple alternative queries and retrieves documents for each.

2. [Hypothetical Document Embeddings(HyDE)](agentic_ai/advance_rag_techniques/1_query_enhancement/hyde.ipynb): Generates a hypothetical answer/document and embeds it for retrieval.
